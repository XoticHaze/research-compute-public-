# Fund Model Parallel Stack R1

Objective: demonstrate multi-parallel fund-model construction rather than broad research branching.

This branch runs four independent, fund-relevant discriminators in parallel from the existing public-compute evidence base:

1. **Relative-momentum persistence** — retest the surviving SMH/QQQ relative-momentum sleeve with stricter rolling-origin folds and cost sensitivity.
2. **Risk-state conditioning** — test whether volatility/risk-state conditioning improves the same sleeve without hiding weak eras.
3. **Capital-allocation challenger** — compare static 50/50, winner-take-most, and capped risk-weighted allocation under matched costs and turnover.
4. **Portfolio diversification test** — measure whether combining the relative-momentum sleeve with a broad-market anchor improves after-cost Sharpe/Calmar and drawdown versus the strongest standalone baseline.

Every child must emit: matched baseline, after-cost excess, fold persistence, turnover/cost sensitivity, drawdown, Sharpe/Calmar, and promote/iterate/park/kill decision.

This is intentionally not a broad indicator search. All children are variations of the same investable stack: selection -> state conditioning -> allocation -> portfolio risk.
