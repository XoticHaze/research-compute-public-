# Same-firing execution rule

This lane is intentionally a single coherent fund-model tree with four independently executable children. The desired pass behavior is:

- launch all independent children together;
- do not poll one child while siblings are runnable;
- consume terminal child results into one comparison table;
- promote only components that improve the investable stack after costs and across folds;
- park or kill children that fail matched-baseline tests;
- immediately derive the next discriminator from the surviving component rather than opening unrelated research branches.

The four children map to one stack:

selection persistence -> risk-state conditioning -> allocator competition -> portfolio diversification.
