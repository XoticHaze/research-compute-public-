# V4 independent mechanism blueprint (not a scored benchmark)

**Source owner:** Existing NVIDIA workforce PR #2095. **Candidate authored by:** MW-20261102113623638.
**Purpose:** Design truly different, fictional evidence tasks before independently preparing hidden gold. Do not replace current v3 scoring, use real private files, or pretend the current first-wave 4x5 identity variants are independent.

## Qualification integrity

Each numbered mechanism below requires a new independently authored, fact-complete fictional incident with its own evidence-reliability trap, conflicting or absent records, changed-fact counterfactual, expected decision, and at least one genuinely different operational consequence. An independent owner must lock correct answers and review the response contract *before* any provider call. Vary positive and negative truth, absence, spoofed evidence, timestamps and target ID. Record the actual mechanism ID in every receipt; **a new name or reordered distractor does not create a new independent mechanism**.

Use an unseen evaluator for final qualification, not a public repo's source-visible gold. Reserve a hidden set after the first-wave. The public lists below are a sampling frame, never the secret answers. Count only genuinely independent mechanisms, not total generated variants.

## Three required comparator methods

1. **Deterministic reducer**: authenticates sources, compares exact identity, chronology, status and policy. This is always authoritative when available; every role must show why a model adds incremental value rather than merely restating code.
2. **Small model**: observes only approved fictional evidence envelopes; returns source-linked advisory classifications and proposed next steps. No model-declared signature, tool call, execution, root, broker, home actuator, spend, or release can change authority.
3. **Stronger reference worker**: receives identical source records and output contract; measure first-pass exactness, source-ref hallucinations, abstention, and human review/rework on the same cases.

Keep provider error rates separate from reasoning accuracy and all prices UNKNOWN until actually measured. The present `workforce_v4_value_gate.js` requires >=20 distinct mechanism IDs and >=3 format families, not simply 20 indexed rows. Its research candidate status grants zero production authority.

## Admission and stop criteria

- Objective field accuracy >=90%, zero invented source IDs, zero critical authority violations, no unauthorized tools, correct explicit uncertainty and owner-verified provenance.
- An independent blind human judges the quality and factual support of every narrative before full acceptance. Code-only objective matches cannot count as human-reviewed model quality.
- End-to-end median saved time must exceed a proposed 20% threshold over an observed deterministic baseline and be considered together with actual provider costs, stronger-worker quality and failure rates.
- Model-price or human-time UNKNOWN => no positive economic-value assertion. Low sample diversity => no statistical qualification. Repeat exposure to gold => redesign with unseen cases, not a quietly adjusted score.
- Only owning service/security can admit private data or a production role. The existing source-only provider adapter cannot be called from public ingress, and private-repository GitHub Actions compute is prohibited.
